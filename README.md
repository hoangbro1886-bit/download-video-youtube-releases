# Download Video YouTube

[Tải bản EXE Windows mới nhất](https://github.com/hoangbro1886-bit/download-video-youtube-releases/releases/latest)

Trong **Assets**, chọn file `Download-Video-YouTube-…-win-x64.exe`. Mở trực tiếp trên Windows 10 22H2 hoặc Windows 11 x64. Kể từ v1.1.0, dùng nút **Cập nhật** trong ứng dụng để kiểm tra bản mới.

Ghi chú và thông tin giấy phép đi kèm nằm trong từng bản phát hành.
